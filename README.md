# ztal-interview (Template)

Use this repository as a GitHub template to create your own interview assignment repository.

## Create Your Repo From This Template

### Option 1: GitHub UI

1. Open this repository on GitHub.
2. Click **Use this template**.
3. Select **Create a new repository**.
4. Choose your org/user, repository name, and visibility.
5. Create the repository and clone it locally.

### Option 2: GitHub CLI

```bash
gh auth login
gh repo create <your-org-or-username>/ztal-interview --template ztal-prismind/ztal-interview --private --clone
```
